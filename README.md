# Followers EX

Be the Pokemon, multi-follower packs, trainer-at-back, party/BOX LEADER, and Wilds of Kanto encounters that use PokéPC follower walk sheets.

## Requires

- **PokéPC Followers (Voxel Merge)** — `PokePCFollowers_VoxelMerge` (Antigravity)
- **Wilds of Kanto** — `overworld_wild_spawns`

Optional: **Shiny Pokemon** for sparkles on shiny followers and wilds.

## Install

1. Install and enable PokéPC Followers and Wilds of Kanto
2. Enable Followers EX
3. Disable standalone **Wilds Follower Sprites** if you still have it

## OPTIONS

**FOLLOWERS EX → OPEN** — CONTROL MODE (TRAINER/POKEMON), TRAINER FOLLOWS, FOLLOWERS, SHOW IN MENU, WILDS SPRITES.

## Party (on the leader)

- TRAINER — control the trainer again
- BE MON — you are the Pokemon (solo)
- +TRAINER — Pokemon leads, trainer at the back of the line
- PACK N — Pokemon leads with N party followers (◀▶ changes N)

## Bill's PC

**BOX LEADER** — choose a boxed Pokemon as the overworld leader.
